# frontend

React/TypeScript-клиент Overmindv. Браузер работает только с GraphQL API `api-gateway` и не обращается к backend-сервисам напрямую.

## Возможности

- регистрация, вход, хранение JWT и редактирование профиля;
- каталог университетов, программ, курсов и тем через `entities`;
- управление пользователями через `users`;
- опубликованные IT-тесты с фильтрами и pagination;
- решение `single_choice` и `multiple_choice` тестов;
- решение `programming`-задач загрузкой файлов Python или Go с отображением асинхронного результата проверки;
- сохранение и отображение истории попыток;
- уведомление, если открытая версия теста успела обновиться;
- административное создание, версионирование, публикация, архивация и soft delete тестов.
- пакетный сбор до 20 ссылок CodeRun, LeetCode и Codeforces с отдельным статусом каждого URL;
- очередь модерации собранных programming-задач с условием, открытыми примерами и ограничениями.

Все пользовательские ошибки показываются нейтральным текстом. Технические коды остаются в GraphQL `extensions.code` и серверных логах.

## Маршруты задач

Пользовательские страницы:

- `/tasks` — опубликованные тесты;
- `/tasks/:id` — решение актуальной версии;
- `/history` — история попыток авторизованного пользователя.
- `/history/:id` — повторное получение сохранённого результата.

Административные страницы:

- `/admin/tasks` — список и lifecycle тестов;
- `/admin/tasks/new` — создание черновика;
- `/admin/tasks/:id` — полная замена содержимого новой версией.
- `/admin/collected-tasks` — пакетный запуск website-сбора и журнал результатов.
- `/admin/collected-tasks/:id` — проверка и публикация собранного кандидата.

Темы для административной формы загружаются отдельным GraphQL query из `entities`. `frontend` не знает URL `tasks` и отправляет все операции через `api-gateway`.

На странице `programming`-задачи условие, открытые тесты и ограничения расположены слева, а выбор языка, файла и результат — справа. Допускаются `.py` и `.go` файлы размером до 256 КБ. После отправки клиент опрашивает GraphQL query результата до завершения проверки.

## Локальная разработка

Требования: Node.js 22.15+ и доступный `api-gateway`.

```bash
cp .env.example .env
npm ci
npm run dev
```

По умолчанию приложение открывается на `http://localhost:5173`, а GraphQL API — на `http://localhost:8081/graphql`.

Команды проверки:

```bash
npm run lint
npm run typecheck
npm run test:ci
npm run build
```

## Docker и infra

Docker image собирает статические Vite-ресурсы и запускает непривилегированный Nginx на порту `3000`. Внутренний `/graphql` проксируется в `http://api-gateway:8081/graphql`.

```bash
docker build -t frontend:local .
```

Полное локальное окружение запускается из репозитория `infra`.
