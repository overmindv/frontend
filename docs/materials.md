# Материалы

- `/materials` открывает опубликованный каталог. Тема и курсор хранятся в URL.
- `/materials/:id` читает `publishedMaterial`. Запрос не использует Apollo-кэш редактора. Если ID ревизии не совпадает с ID публикации, текст не рендерится.
- История доступна владельцу. Она загружается при открытии раздела, без текста старых версий.
- В Markdown не включен raw HTML. Картинки из текста не загружаются. Поддерживаются HTTPS-ссылки, якоря и внутренние ссылки на материалы, темы и задачи.
- Ссылка на вложение получается по запросу в Media через Gateway. Задай `VITE_MEDIA_DOWNLOAD_ORIGINS` списком origin через запятую, например `https://files.example.org`. HTTP разрешен только для loopback.

Роуты требуют сессию. Gateway должен поддерживать поле `publishedMaterial`.
Закрепленную схему в `schema/` обновляй из артефакта CI Gateway.

## Черновики

- `/materials?view=drafts` показывает черновики текущего пользователя. `/materials/new` создает черновик, а `/materials/:id/edit` открывает его автору.
- При сохранении редактор передает ID ожидаемой ревизии. Если сервер сообщает о конфликте, локальные правки остаются в форме. Загрузка новой версии занимает их место только по явному действию автора.
- Вложение отправляется напрямую в хранилище по подписанной форме. Для загрузки разрешены те же origin из `VITE_MEDIA_DOWNLOAD_ORIGINS`. Редактор принимает по одному файлу до 20 МБ и ожидает статус `ready` в Media перед добавлением в черновик.
- Для редактирования заголовка и тем нужны версии Gateway и Content с поддержкой `SaveContentDraft`. Новая версия Gateway не перезаписывает текст отдельно, когда старый Content не поддерживает эту операцию.

## Предложения правок

- «Предложить правку» открывает редактор от опубликованной версии. Ссылка на предложение имеет вид `/materials/changes/:changeId`.
- Сравнение показывает основание и выбранную версию предложения. История запрашивается отдельно, по 15 версий. `truncated` от Gateway означает неполное сравнение, а не отсутствие изменений.
- Добавлять версии и закрывать открытое предложение может его автор. При сохранении передается `expectedHeadId`. Если версия изменилась, редактор не отправляет правки повторно и не очищает форму.
- Для всех маршрутов материалов нужна сборка Gateway с API чтения публикаций, черновиков и предложений.
