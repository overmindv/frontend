# OVM-81 — минималистичный учебный интерфейс

Исполнитель: Alexander Vasyukov. Пользователь поручил выбрать и реализовать направление самостоятельно.

## Дизайн и границы
Существующий React, без зависимостей и изменения API. Светлая нейтральная основа, синий акцент, сохранение тёмной темы. Основные действия — решать задачи и читать материалы. Каталог раскрывается по запросу; администрирование остаётся доступным. Главная даёт прямые входы в задачи и материалы, новости вторичны. Фильтры задач располагаются компактно над результатами и не выходят за границы при длинных названиях. Сохранены поиск, сброс, пагинация и ошибки. Анимация только короткого отклика с reduced-motion.

Рассмотрены: косметическая смена палитры (не решает перегрузку); полная замена frontend/Vue (дорого и пересекается с работой Лёни); выбран локальный пересмотр навигации и учебных экранов.

Не трогаем backend, редактор/ревью материалов, схемы GraphQL, общий стек. Общие токены проверяем на материалах. Worktree codex/ovm-81-learning-ui; исходный main не меняем.

## Проверяемые риски
- Длинная тема: select остаётся внутри контейнера.
- Телефон: меню и админ доступны, нет горизонтального скролла.
- Ошибка API: не выдаётся за пустой список; повтор сохраняет фильтры.
- Тёмная тема: контраст текста и главной кнопки.
- Материалы: чтение и редактор не меняют поведение.

## Отложено по просьбе пользователя
Вернуться после редизайна к разграничению: общие задачи проходят ревью другими администраторами; личный курс может содержать собственные задачи/материалы без внешнего согласования. Это продуктовая гипотеза, не реализованное правило. Календарное напоминание не назначено.
